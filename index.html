RadioSatt

Music Request, Made Simple.

RadioSatt adalah aplikasi Windows yang sedang dikembangkan untuk membantu kreator livestream mengelola permintaan lagu dari penonton melalui TikTok LIVE.

Tentang RadioSatt

RadioSatt mengintegrasikan YouTube Data API untuk mencari video musik berdasarkan permintaan lagu penonton. Aplikasi ini membantu streamer mengelola hasil pencarian dan antrean permintaan lagu secara lebih terorganisasi.

Platform

RadioSatt dikembangkan sebagai aplikasi desktop untuk Windows.

Penggunaan YouTube API

YouTube Data API digunakan untuk mendukung fungsi pencarian video musik. RadioSatt tidak mengunduh atau mengunggah ulang video YouTube.
