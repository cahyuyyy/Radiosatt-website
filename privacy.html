Privacy Policy

Last updated: November 8, 2026

RadioSatt respects your privacy. This Privacy Policy explains how RadioSatt handles information when you use the application.

1. Information We Process

RadioSatt processes information from TikTok LIVE interactions, such as usernames, comments, and song requests, to provide music request and queue management features.

This information is processed temporarily while the application is running. RadioSatt does not intentionally store viewers' personal information in a permanent database or on the developer's servers.

2. YouTube Data API Services

RadioSatt uses YouTube Data API Services to search for music videos based on song requests.

Your use of RadioSatt is also subject to the YouTube Terms of Service and Google Privacy Policy .

3. Third-Party Services

RadioSatt may interact with third-party services, including TikTok, EulerStream, and YouTube, to provide its features. These services may process information according to their own privacy policies and terms.

4. API Keys and Local Configuration

API keys used by RadioSatt are configured by the application user and are used to connect to the relevant services. Configuration and application settings may be stored locally on the user's computer.

RadioSatt does not intentionally transmit API keys to the application developer.

5. Data Security

Users are responsible for protecting their computers and API credentials. We recommend keeping API keys private and not sharing them with other people.

6. Changes to This Policy

This Privacy Policy may be updated when RadioSatt's features or data practices change. The latest version will be published on this page.

7. Contact

If you have questions about this Privacy Policy, please contact the RadioSatt developer through the official RadioSatt project page.
